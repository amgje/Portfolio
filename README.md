# Portfolio site — version 2

Plain HTML + CSS.

Design changes:
- warm off-white background instead of dark/grey UI
- no cards, pills, badges or metric boxes
- Georgia serif used for section labels and headings
- projects arranged editorially rather than as dashboard cards
- metrics on case-study pages shown as a simple line, not boxes

Before publishing, replace:
- YOUR_EMAIL_HERE
- YOUR_LINKEDIN_URL_HERE

Preview:
Open index.html, or run:
python -m http.server 8000
