Portfolio project 01

Scientific data cleaning & automated QC for optical sensor measurements

Synthetic case study showing how I handle inconsistent experimental files, missing data, duplicate rows, anomalous spikes and repeatable calibration analysis.

30input CSV files
12,000measurements
51QC issues flagged and handled
Problem

Messy experimental data before analysis.

The source files contained inconsistent headers, duplicated rows, missing signal measurements, malformed numeric values and transient spikes. The goal was a reusable workflow that cleaned the data without silently altering it.

Raw files → schema standardisation → QC → spike detection → interpolation → clean master dataset

Raw and cleaned example showing automatically detected signal spikes.

Quality control

Every correction was recorded.

The pipeline standardised schemas, recovered numeric measurements stored as text, removed exact duplicate rows, flagged missing measurements and detected anomalous spikes. QC flags were retained in the final dataset.

Automated QC summary across all 30 files.

Result

Clean data to calibration result.

The cleaned measurements were normalised against the reference channel, summarised across five repeated runs at each concentration, and used to produce a reproducible calibration analysis.

Tools: Python · pandas · NumPy · Matplotlib · robust outlier detection · batch processing
