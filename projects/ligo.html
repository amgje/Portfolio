Project 02

Extracting a gravitational-wave signal from LIGO detector data

A rebuilt MSc signal-processing case study using real public HDF5 strain data from the Hanford and Livingston detectors.

4096 Hz sampling rate30–300 Hz analysis band4.64 ms estimated detector lag

The problem

A weak transient hidden in detector noise.

Gravitational-wave strain measurements are dominated by detector noise. I rebuilt the analysis as a clear Python workflow using spectral whitening, zero-phase band-pass filtering and detector alignment.

Raw Hanford and Livingston detector strain around the event.

Processing

From raw strain to an interpretable transient.

I used the detector noise spectrum to whiten the measurements, then applied a zero-phase Butterworth filter. Cross-correlation over the event region estimated the relative timing offset between the two observatories.

HDF5 → event window → PSD estimation → whitening → 30–300 Hz band-pass → cross-correlation → alignment

Raw, whitened and band-limited processing stages.

Time-frequency analysis

Tracking how the signal changes in frequency.

A focused spectrogram reveals the transient's changing frequency content through the event region, complementing the recovered time-domain waveform.

Python, NumPy, SciPy, h5py, HDF5, FFT, PSD estimation, digital filtering, cross-correlation, spectrograms
