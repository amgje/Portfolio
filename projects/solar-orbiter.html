Portfolio project 03

Modelling dust impacts in Solar Orbiter spacecraft data

Signal preprocessing, instrument correction, physics-based nonlinear fitting and mission-scale population analysis using Solar Orbiter RPW telemetry.

6 monthsof observations analysed
1,920successfully fitted signals
1,550quality-controlled fits
Preprocessing

Correcting the measurement chain before fitting.

The raw RPW waveforms required DC-offset removal, numerical correction of an artefact introduced by the onboard 200 Hz high-pass filter, event extraction and 8-point running-average filtering.

Raw waveform → DC correction → instrument-response correction → event extraction → low-pass filtering → resampling

Progressive preprocessing of a dust-impact waveform.

Physical model fitting

Seven fitted parameters from each event.

I fitted a physical model describing the separate spacecraft and antenna potential responses. SciPy nonlinear optimisation estimated collected charge, relaxation times, rise time, charge fraction and separate response start times.

Fits were assessed not only by residual error, but also by whether parameter estimates were physically plausible.

Measured voltage perturbation, total model fit and the spacecraft/antenna components.

Population analysis

Scaling from one waveform to thousands.

The single-event analysis was turned into an automated batch pipeline. After fitting 1,920 signals, boundary-limited and implausible parameter estimates were removed, leaving 1,550 quality-controlled fits for population analysis.

Tools: Python · NumPy · SciPy · cdflib · numerical integration · nonlinear least-squares fitting · uncertainty analysis · batch processing · QC

Population distribution of fitted spacecraft and antenna relaxation times.

Mission-scale context

Joining fitted parameters with spacecraft ephemeris data.

The fitted event table was combined with Solar Orbiter heliocentric distance data to examine whether fitted parameters varied across the mission trajectory.

Individual fitted events and binned population behaviour versus distance from the Sun.
